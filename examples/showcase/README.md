# Showcase project

This is the playable beginning of the public reference game described in `BUILD_PLAN.md`. Its ten-scene lighthouse story runs through the real compiler, deterministic runtime, and production player. Recent narration and dialogue remain on the stage, the newest two speakers form an opposing desktop duet, and choice and ending views keep the conversation that produced them. Four recurring speakers use distinct frame geometry, typography, palettes, and urgent, radio, memory, command, quiet, wry, steady, relieved, and distant effects. The entire presentation is semantic text and CSS; it deliberately proves that character identity and visual variety do not require portraits, scene paintings, or other authored artwork. The routes also demonstrate interpolation, emphasis, language and pronunciation markup, choices, state-gated options, deterministic weather, conditions, calls/returns, effects, three endings, chronological history, and manual/quick/automatic saves with JSON import and export. It is an ordinary manifest-backed engine project. `pnpm build:showcase:pages` sends it through the shared release web exporter, verifies the repository-relative artifact, and reproduces the folder deployed to [GitHub Pages](https://zeidalidiez.github.io/RPGNarrativeEngine/). The published build is an offline-capable PWA with an explicit update prompt.

It is not yet the complete RPG showcase. World exploration, combat, inventory, progression, themes, audio, localization fixtures, and the Systems Gallery will arrive with their corresponding engine systems.
