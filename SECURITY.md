# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put creators, players, project files, signing credentials, or build machines at risk.

Use GitHub's private vulnerability reporting for this repository when it is available. Otherwise, contact the repository owner privately through the contact method on their GitHub profile. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Do not include real secrets or private user data.

The project will acknowledge a report as soon as a maintainer is available, investigate it, and coordinate disclosure after a fix or safe mitigation exists. This volunteer project cannot promise a commercial response-time SLA, but security reports will be treated seriously.

## Supported versions

Until the first public release, only the current `main` branch is supported. A release support table will replace this statement once versioned releases exist.
